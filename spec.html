X Tagger 仕様書

X(旧Twitter)のタイムラインを、自分好みに整理するChrome拡張機能

これは何?

パソコンのChromeブラウザに入れて使う拡張機能です。x.com を開くと自動で動き出し、タイムラインを見やすく整理してくれます。プログラミングの知識がなくても使えます。

※ スマホアプリのXには効きません。Androidなら Firefox / Kiwi Browser に入れることで使えます。

できること

1広告を消す

タイムラインに混ざってくる「プロモーション」(広告ツイート)を自動で見えなくします。

2ツイートにタグを付ける

自分で登録した単語(タグ)がツイート本文に入っていたら、ツイートの上にメルカリの検索画面のような丸いチップを表示し、左端に青いバーを付けます。パッと見で「興味のあるツイート」が分かります。

Python  機械学習
今日はパイソンで機械学習のコードを書いてた。楽しい。

同義語: 「Python」タグに「パイソン」「python3」を登録しておくと、どの書き方でも同じチップが1つだけ付きます(3つ並びません)。

除外語: 「猫の話は見たいけど猫背の話は要らない」なら、「猫」タグに除外語「猫背」を設定。「猫背」としか書いていないツイートには反応しなくなります。

3よく流れてくる単語を自動でタグにする

流れてきたツイートの単語を裏で数えていて、設定した回数(初期値: 20回)以上出てきた単語は自動でタグに昇格します。自動タグはグレーのチップで表示され、自分で登録した青いタグと区別できます。いらない自動タグは×で消せて、一度消すと二度と復活しません。

4タグに合うツイートだけ表示する(フィルタモード)

設定でONにすると、ホームタイムラインでどのタグにも当てはまらないツイートを非表示にします。興味のある話題だけが流れるタイムラインになります。

タグのヒット率が低いと画面がスカスカになるため、初期設定ではOFFです。プロフィールページやツイート詳細ページでは動作しません。

使い方

インストール

  1. Chromeで chrome://extensions を開く
  2. 右上の「デベロッパーモード」をON
  3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

タグの登録

  1. ツールバーのパズルピースアイコン → X Tagger をクリック
  2. 入力欄に単語を入れて「追加」
  3. チップの文字部分をクリックすると同義語・除外語の編集パネルが開く
  4. チップの「×」で削除

設定項目

設定初期値説明
広告(プロモーション)を非表示ON広告ツイートを隠す
タグに一致しないツイートを非表示OFFフィルタモード(ホームTLのみ)
頻出単語の自動タグ化ONよく出る単語を自動でタグにする
自動タグ化のしきい値20回何回出てきたら自動タグにするか

ポップアップには「頻出単語 上位」ランキングも表示され、「＋タグに追加」で手動でタグにできます。

仕組み(やさしい解説)

拡張機能って何をしているの?

Webページに常駐する「お手伝いさん」です。x.comが開くと一緒に起動し、表示されるツイートを1つずつチェックして「広告なら隠す」「タグの単語が入っていたらチップを貼る」を繰り返します。

どうやって新しいツイートに気づくの?

「ページの変化を知らせてくれる見張り役」(MutationObserverという仕組み)を使い、スクロールで新しいツイートが現れた瞬間に検査しています。

同じツイートを二重に処理しない工夫は?

Xは表示を軽くするため、画面外に出たツイートの「入れ物」を別のツイートに使い回します。X Taggerは各ツイートの固有URLを名札として記録し、入れ物の中身が変わったら検査し直し、一度単語を数えたツイートは再表示されても数え直さないようにしています。

日本語の単語はどうやって数えているの?

日本語は単語の間にスペースがないため分割が難しいのですが、Chromeに内蔵されている日本語分割機能(Intl.Segmenter)を使っています。さらにURL・メンション・「する」「こと」などの意味の薄い言葉・2文字以下のひらがなだけの言葉(助詞がほとんど)は数えません。

タグの判定の細かいルールは?

大文字/小文字、全角/半角は区別しません。英数字の単語は単語の区切りを見て判定するので「python」タグが「python3」に誤反応しません。日本語は部分一致なので、誤反応する場合は除外語で調整します。

データはどこに保存されるの?

タグ・設定・単語カウントはすべて自分のパソコンのChromeの中に保存されます。外部のサーバーには何も送信しません。ツイートの内容も外に出ません。

Xのデザインが変わったら壊れない?

Xは見た目のクラス名を頻繁に変えるため、代わりにX自身がテスト用に付けている目印(data-testid)を頼りにしています。変更頻度が低く比較的長持ちしますが、大規模な改修で動かなくなる可能性はあります。

開発の経緯(直したこと)

  1. 最初のバージョン: 広告非表示 + 単語タグ + 頻出単語カウントを実装
  2. タグのオブジェクト化: 「Python/パイソン/python3が別チップになる」「除外語が書けない」問題を、タグを「表示名+同義語+除外語」のセットにして解決
  3. 単語境界の判定: 英数字の単語が別の単語の一部に誤反応する問題を修正
  4. 重複カウントの修正: スクロールの往復で同じツイートが何度も数えられる問題を、固有URLの記録で解決
  5. ハイライト消失の修正: カーソルを乗せると青い印が消える問題を、Xのホバー背景より手前に描画して解決
  6. フィルタモード追加: タグに一致するツイートだけ表示するモードを、ホームTL限定・初期OFFで追加

既知の制限

  • ページをリロードすると「数えたツイート」の記録が消えるため、同じツイートが再カウントされることがある(カウントは傾向を見る目的なので許容)
  • フィルタモードでタグのヒット率が低いと、画面がほぼ空になる
  • Xの大規模なデザイン変更で動かなくなる可能性がある
  • スマホのChromeでは拡張機能自体が使えない(Android: Firefox / Kiwi Browser で代用可)
