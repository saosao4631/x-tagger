X Tagger 仕様書

X(旧Twitter)のタイムラインを、自分好みに整理するChrome拡張機能

これは何?

パソコンのChromeブラウザに入れて使う拡張機能です。x.com を開くと自動で動き出し、タイムラインを見やすく整理してくれます。プログラミングの知識がなくても使えます。

※ スマホアプリのXには効きません。Androidなら Firefox / Kiwi Browser に入れることで使えます。

できること

1広告を消す

タイムラインに混ざってくる「プロモーション」(広告ツイート)を自動で見えなくします。

2ツイートにタグを付ける

自分で登録した単語(タグ)がツイート本文に入っていたら、ツイートの上にメルカリの検索画面のような丸いチップを表示し、背景を薄い青色にします。

Python  機械学習
今日はパイソンで機械学習のコードを書いてた。楽しい。

同義語: 「Python」タグに「パイソン」「python3」を登録しておくと、どの書き方でも同じチップが1つだけ付きます(3つ並びません)。

除外語: 「猫の話は見たいけど猫背の話は要らない」なら、「猫」タグに除外語「猫背」を設定。「猫背」としか書いていないツイートには反応しなくなります。

3よく流れてくる単語を自動でタグにする

登録したタグにヒットしたツイートの単語を裏で数えていて、設定した回数(初期値: 20回)以上出てきた単語は自動でタグに昇格します。自動タグはグレーのチップで表示され、自分で登録した青いタグと区別できます。いらない自動タグは×で消せて、一度消すと二度と復活しません。

集計対象を「タグにヒットしたツイート」に絞っているので、例えば「Python」タグを登録しておくと、Python関連のツイートの中で一緒によく出てくる単語(「Django」「機械学習」など)が上位に出ます。興味の周辺にある関連ワードを見つけるのに使えます。

タグを1つも登録していないうちは、この集計は始まりません(何を基準に集めるかが決まらないため)。まず興味のあるタグを1つ登録してください。

4タグセットの切り替え

タグの一覧を「セット」として複数保存し、ワンクリックで切り替えられます。「趣味セット」「仕事セット」を作って気分でタイムラインの見え方を変える、といった使い方ができます。タグの追加・編集はいま選んでいるセットに自動保存され、切り替えるとタイムラインの表示も即座に変わります。セット名はダブルクリックでその場で変更できます。頻出単語・自動タグ・頻出単語の除外リストはセット別に保存されます。

タグの追加・削除や同義語・除外語の変更で判定条件が変わると、そのセットの集計・自動タグを作り直します。セット名だけの変更では集計を保ちます。「このセットの集計・自動タグをリセット」は選択中のセットだけに反映され、登録タグと頻出単語の除外リストは保持します。開いているXタブの古いカウントが再保存されることもありません。

修正版への更新後、以前の共通集計・自動タグは新しいランキングに引き継がず、セット別に集計を始めます。登録タグと手動で除外した語は引き継ぎます。

5AIによるお手伝い(Chrome内蔵AI・対応マシンのみ)

Chrome内蔵AI(Gemini Nano)を使った補助機能です。APIキー不要・費用ゼロで、モデルのダウンロード後はデータが一切外部に送信されません。

  • 同義語・除外語の候補生成: タグ編集パネルの「AIで候補を出す」で、表記ゆれや誤ヒットしそうな語の候補をAIが提案。候補はチェック式で、ユーザーが選んだものだけ反映されます
  • 頻出単語のノイズ除去: 「AIでノイズ候補を出す」で候補を表示。最初はすべて未選択で、ユーザーが選び「選んだ語を除外」を押したものだけ、そのセットの除外リストへ移動します。キャンセルすると変更しません。セット・タグ条件の変更やリセット時には古い候補を破棄します
AI対応マシン(空きストレージ22GB、十分なGPU/メモリ)でのみボタンが表示されます。非対応でも他の機能は通常通り使えます。初回はAIモデル(数GB)のダウンロードが必要です。

6タグに合うツイートだけ表示する(フィルタモード)

設定でONにすると、ホームタイムラインでどのタグにも当てはまらないツイートを非表示にします。興味のある話題だけが流れるタイムラインになります。

タグのヒット率が低いと画面がスカスカになるため、初期設定ではOFFです。プロフィールページやツイート詳細ページでは動作しません。

使い方

インストール

  1. Chromeで chrome://extensions を開く
  2. 右上の「デベロッパーモード」をON
  3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

タグの登録

  1. ツールバーのパズルピースアイコン → X Tagger をクリック
  2. 入力欄に単語を入れて「追加」
  3. チップの文字部分をクリックすると同義語・除外語の編集パネルが開く
  4. チップの「×」で削除

設定項目

設定初期値説明
広告(プロモーション)を非表示ON広告ツイートを隠す
タグに一致しないツイートを非表示OFFフィルタモード(ホームTLのみ)
頻出単語の自動タグ化ONよく出る単語を自動でタグにする
自動タグ化のしきい値20回何回出てきたら自動タグにするか

ポップアップには「頻出単語 上位」ランキングも表示され、「＋タグに追加」で手動でタグにできます。単語の横の「×」を押すと、そのセットのランキングから除外され、自動タグにも昇格しなくなります。他のセットには影響しません。

仕組み(やさしい解説)

拡張機能って何をしているの?

Webページに常駐する「お手伝いさん」です。x.comが開くと一緒に起動し、表示されるツイートを1つずつチェックして「広告なら隠す」「タグの単語が入っていたらチップを貼る」を繰り返します。

どうやって新しいツイートに気づくの?

「ページの変化を知らせてくれる見張り役」(MutationObserverという仕組み)を使い、スクロールで新しいツイートが現れた瞬間に検査しています。

同じツイートを二重に処理しない工夫は?

Xは表示を軽くするため、画面外に出たツイートの「入れ物」を別のツイートに使い回します。X Taggerは各ツイートの固有URLを名札として記録し、入れ物の中身が変わったら検査し直し、一度単語を数えたツイートは再表示されても数え直さないようにしています。

日本語の単語はどうやって数えているの?

数える対象は登録タグにヒットしたツイートだけです(タグに関連する話題の中で他に何が頻出しているかを見るため)。日本語は単語の間にスペースがないため分割が難しいのですが、Chromeに内蔵されている日本語分割機能(Intl.Segmenter)を使っています。数えるのはほぼ名詞だけです。動詞・形容詞・助詞は「食べる」「楽しい」「から」のようにほぼ必ずひらがなを含むため、ひらがなを含む言葉を除外し、漢字・カタカナ・英数字だけの言葉(猫、機械学習、ゲーム、Pythonなど)に絞っています。URL・メンション・「今日」などの意味の薄い言葉も数えません。

タグの判定の細かいルールは?

大文字/小文字、全角/半角は区別しません。英数字の単語は前方一致で、「run」タグは running / runner にもヒットします(活用形をまとめて拾うため)。「cat」で catch が引っかかるような不要ヒットは、除外語に「catch」を追加して弾きます。日本語は部分一致なので、誤反応する場合は同じく除外語で調整します。

データはどこに保存されるの?

タグ・設定・単語カウントはすべて自分のパソコンのChromeの中に保存されます。外部のサーバーには何も送信しません。ツイートの内容も外に出ません。

Xのデザインが変わったら壊れない?

Xは見た目のクラス名を頻繁に変えるため、代わりにX自身がテスト用に付けている目印(data-testid)を頼りにしています。変更頻度が低く比較的長持ちしますが、大規模な改修で動かなくなる可能性はあります。

開発の経緯(直したこと)

  1. 最初のバージョン: 広告非表示 + 単語タグ + 頻出単語カウントを実装
  2. タグのオブジェクト化: 「Python/パイソン/python3が別チップになる」「除外語が書けない」問題を、タグを「表示名+同義語+除外語」のセットにして解決
  3. 単語境界の判定: 英数字の単語が別の単語の一部に誤反応する問題を修正
  4. 重複カウントの修正: スクロールの往復で同じツイートが何度も数えられる問題を、固有URLの記録で解決
  5. ハイライト消失の修正: 当初は青い縦線を重ねて対応。その後、縦線を廃止し、タグチップと薄い背景色で表示
  6. フィルタモード追加: タグに一致するツイートだけ表示するモードを、ホームTL限定・初期OFFで追加
  7. 広告判定の強化と英単語の前方一致化: 広告ラベルの表記ゆれ(広告/Ad等)に対応。英単語の判定を前方一致にして「run」で running / runner も拾えるように(不要なヒットは除外語で対処)
  8. 頻出単語を名詞のみに: ひらがなを含む語を除外し、動詞・形容詞・助詞がカウントされないように
  9. UI刷新とタグセット機能: ポップアップをカード型+トグルスイッチに刷新。タグ一覧を複数の「セット」として保存し、ワンクリックで切り替えられる機能を追加
  10. AI機能の追加: Chrome内蔵AI(Gemini Nano)による同義語・除外語の候補生成と頻出単語のノイズ除去。AIは提案役に徹し、確定は必ずユーザーが行う設計
  11. 頻出単語をタグ関連ツイートに限定: 登録タグに一致した投稿だけから関連する単語を集計
  12. 集計の分離とリセット修正: 集計・自動タグ・除外リストをセット別に保存。タグ条件変更で再集計し、リセット前のタブから遅れて届く保存は破棄
  13. AIノイズ除去の確認: AIの結果を即時保存せず、ユーザーが選択・確定した候補だけを除外

既知の制限

  • ページをリロードすると「数えたツイート」の記録が消えるため、同じツイートが再カウントされることがある(カウントは傾向を見る目的なので許容)
  • フィルタモードでタグのヒット率が低いと、画面がほぼ空になる
  • Xの大規模なデザイン変更で動かなくなる可能性がある
  • スマホのChromeでは拡張機能自体が使えない(Android: Firefox / Kiwi Browser で代用可)
