# X Tagger

x.com(Twitter)のタイムラインを拡張する Chrome 拡張機能。

## 機能

1. **広告の非表示** — Promoted(プロモーション)ツイートを自動で隠す
2. **キーワードタグ** — 登録したタグの単語がツイート本文に含まれていたら、ツイートの上にメルカリ検索風のチップを表示し、背景を薄い青色にする
   - タグには**同義語**を設定できる(例:「Python」に `パイソン, python3`)。どの同義語にヒットしてもチップは表示名1つだけ
   - タグには**除外語**を設定できる(例:「猫」に `猫背`)。本文から除外語を取り除いてから判定するので、「猫背」しか含まないツイートにはヒットしない
   - ポップアップでチップをクリックすると同義語・除外語を編集できる。単語を打って追加するだけなら従来通り1単語=1タグ
3. **頻出単語の自動タグ化** — 選択中のセットの登録タグに一致した投稿から単語を集計し、しきい値(初期値: 20回)以上で自動タグに昇格。集計・自動タグ・除外リストはセット別に保存。タグ条件変更時は集計を始め直す
4. **AI補助** — Chrome内蔵AIで同義語・除外語や頻出単語のノイズ候補を生成。ユーザーが選択して確定するまで保存しない

初期設定はハイライト方式。設定でフィルタモードをONにすると、ホームタイムラインでタグに一致しない投稿を非表示にする。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ(`x-tagger`)を選択
4. x.com を開き、ツールバーの拡張機能アイコンからキーワードを登録

## 実装メモ

- **仮想スクロール対策**: x.com はスクロールで DOM ノードを使い回すため、ツイートの固有 URL(`/status/...`)を `data-xt-id` に記録し、中身が入れ替わったノードを検出して再処理する
- **セレクタ**: 自動生成クラス名は使わず `data-testid`(`tweet`, `tweetText`, `cellInnerDiv`, `placementTracking`)ベース
- **日本語の単語分割**: Chrome 内蔵の `Intl.Segmenter`(`granularity: "word"`)を使用。外部ライブラリ不要。ストップワード・ひらがなを含む語・絵文字や記号を除外(厳密な品詞判定ではない)
- **データ**: すべて `chrome.storage.local` に保存。単語カウントはセットごとに上位500語を保持し、15秒ごとに差分をバックグラウンドへ送信。保存操作を直列化して複数タブの上書きを防ぐ
- **リセット**: 集計に世代IDを付け、リセット前の差分保存を拒否。リセット対象は選択中のセットの集計・自動タグで、登録タグと除外リストは維持する
- **移行**: 旧形式の共通カウント・自動タグは出所が不明なため新しいランキングに引き継がない。タグと明示的な除外語を保持し、セット別に集計を始める

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manifest.json` | Manifest V3 定義 |
| `content.js` | タイムライン監視・タグ付け・広告除去・単語集計 |
| `background.js` | セット別集計の移行・保存・リセット・自動タグ化 |
| `statistics.js` | 集計形式とバックグラウンドへの通信 |
| `content.css` | チップとハイライトのスタイル |
| `popup.html` / `popup.js` | キーワード管理・頻出単語ランキング・設定 UI |

## テスト

`node --test tests/statistics.test.cjs`

Chrome APIとDOMを模擬し、旧集計の移行、セット分離、複数タブからの加算・リセット、AI候補の選択・確定を検証する。Chrome上での表示やGemini Nanoの生成品質は別途実機確認が必要。
